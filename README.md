Cara membuat APK:
1. Unggah semua isi folder ini ke repositori GitHub (termasuk folder .github).
2. Buka tab Actions > Build APK > Run workflow.
3. Setelah selesai, unduh "kasir-ta-apk" dari bagian Artifacts, ekstrak, lalu pasang APK di HP.

Ikon dan splash memakai logo RX Digital di folder assets (icon-only, icon-foreground, icon-background, splash). Timpa file-file itu untuk menggantinya.
Mengubah aplikasi: edit src/index.html lalu commit.
